## Java Environment

### Things that not feasible to support and are therefore left out:

- Line Comments
- Text blocks
- Raw-source Unicode escape preprocessing
- Annotated types
- Union type casts
- Anonymous classes (!)
- Generic Type Arguments (unsure if I can/want to support generics, but I kinda have to, I fear)
- Super for inner classes with enclosing type stuff, I can well avoid these situations

### For agents:

If you need to create temporary scripts, but them into ./tmp, you can even leave them there for agents to reuse, but mark clearly that they are generated for a single purpose.
